User: Develop a Python framework that continuously collects local system metrics, outputs structured JSON/JSONL and provides automated testing to validate functionality and data integrity.

1. Data Collection
Metrics to collect:
CPU: total usage, per-core usage.
Memory: total, used, free, available.
Disk: per partition total, used, free.
Network: bytes sent and received per interface.
Configurable collection interval (e.g., every 5 seconds).
Use Python libraries like psutil.
Runs under normal user permissions (no root/admin needed).
2. Data Storage
Write collected metrics into JSONL files.
Each record timestamped for time-series analysis.
Example JSONL record:
{"timestamp": 1731462200,"cpu": {"total": 35.5, "per_core": [20.0, 50.0, 30.0, 42.0]},"memory": {"total": 16384, "used": 8192, "free": 4096, "available": 8192},"disk": {"C:": {"total": 512000, "used": 256000, "free": 256000}},"network": {"eth0": {"bytes_sent": 1234567, "bytes_recv": 2345678}} } 
3. Report Generation
Optionally generate JSONL summary reports from collected metrics.
Aggregate statistics per time window:
Average CPU usage
Memory usage trends
Disk and network utilization
Output summary in JSON format.
4. Automated Testing
Test Artifacts:
test_report_template.json to aggregate test results.
Use Python pytest.
5. Project Architecture
collector.py — main metric collection module.
storage.py — JSON/JSONL writing and file rotation.
reporter.py — optional report generation.
config.json — collection interval, output paths.
tests/ — unit and integration test scripts.
run_metrics.sh — script to start collection.
run_tests.sh — run automated tests and generate test report.
6.  Output Artifacts (Mandatory)
For reproducibility and testing, the project must generate:

requirements.txt — Python dependencies.
Dockerfile — containerized environment.
setup.sh — local environment setup.
run_test.sh — demo script for end-to-end test, including automated tests.
README.md — usage guide and API documentation.
test_report_template.json — template for collecting test results.
